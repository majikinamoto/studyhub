# 理科・物理編の作成記録

- 受領範囲：ユーザー提供の本文写真14枚、p.6〜32。表紙・目次の2枚は本文枚数に含めない。
- 全14項目、元の161設問を168問の4択に再構成。
- 力のはたらきの第1問（3つのはたらき）を3問へ、電流の性質の第1問（6記号）を6問へ分割。
- 全問に解説と元のページ・設問番号を付与。各原設問が少なくとも1問に対応。
- 記号だけでは意味が分からない図・グラフ・作図問題は文章へ再構成。図自体の読解を再現したものではなく、同じ法則・関係を確認する問題。
- 例：鏡に当てる位置は対称点を使う作図方法、磁界の図は観察方向を指定した向き、力の図は合成・分解の方向や関係を出題。
- 各問の正答位置は全体で各位置42問。選択肢を選んだだけでは採点せず、「回答する」で確定する既存画面を利用。
- バイオマスは燃焼時に二酸化炭素が出ないという誤解を避け、成長時の吸収との収支の考え方と、生産・輸送による排出を区別。
- ローカル実装まで。理科の公開は未実施。
