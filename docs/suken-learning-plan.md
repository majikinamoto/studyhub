# 数検2級 学習教材の範囲と管理

更新日：2026-09-27
対象：高校数学をまだ習っていない中学2年生。まず1次に向けた計算の基礎を身に付ける。
資料：『実用数学技能検定 要点整理 2級』の提供写真（本文p.14〜175、目次・検定概要・公式チェックポイント）。全9章を受領済み。別冊解答は未受領。

## 今回の実装

既存13項目・65問に、37項目・185問を追加。合計50項目・250問、説明153段階。
1次の基礎は45項目・225問、2次の考え方の入口は5項目・25問。
今回の追加分はローカル実装・検証済み。ユーザーの公開指示に基づき、mainへの反映でGitHub Pagesに配信する。
既存の√・展開因数分解は公開済み。

各項目は「説明→途中の一手2問→自力練習3問」。ヒント、選択後に押す回答ボタン、解説、範囲選択、覚えた印を共通で使う。
解説から説明を別タブで読み直せる。前提分野へ戻るリンクと、練習後に次の項目へ進むリンクを追加した。
三角比、放物線、ベクトル、積分の面積にSVG図解を付けた。

これは提供写真の考え方を参考にしたオリジナルの入門教材であり、全掲載問題の収録、過去問の再現、本番形式の模擬試験ではない。
1次・2次への配置は学習順序のため。掲載問題の印刷上の試験区分を転載したものではない。
今後、写真の個別設問を扱う場合は各設問の1次・2次表示を確認し、章ごとに一括分類しない。
2次の4択は考え方の確認用。記述答案の添削・自動採点はなく、理由と途中式を紙に書く練習を案内する。

## 基礎を終えた後に補う内容

全章への入口は用意したが、次の詳細・応用は未収録。現段階を「教科書を全問習得できる教材」とは扱わない。

- 恒等式の係数決定、相加相乗平均、背理法、解と係数の関係、複素数の除法の練習、整式の筆算、複雑な高次方程式。
- 外分、点と直線の距離、2次不等式、パラメータを含む最大最小、円と直線の交点・接線、複雑な軌跡。
- 正弦定理の練習、三角関数のグラフ・方程式・合成、指数対数の方程式・不等式、底の変換・桁数。
- 微分を使う方程式の解の個数や文章題、条件付きの原始関数、曲線と接線の面積。
- Σの2乗・3乗公式、階差数列・分数の和、漸化式・数学的帰納法の発展。
- ベクトルの外分・一次独立・空間の交点・面積比、円順列・重複順列・同じものを含む順列・組分け。
- 確率の複合問題、数学検定特有の図形・石の取り除き・整数の証明問題。

## ファイルと再生成

- 分野定義：`assets/js/suken-courses.js`。タイトル、前提分野、1次・2次の入口、旧URLを管理。
- 学習画面：`assets/js/suken-learning.js`、`pages/suken-course.html`。新分野はクエリのtopicを許可リストと照合する。
- 旧入口：`pages/suken-roots.html`、`pages/suken-algebra.html`を維持。保存キーも変更しない。
- 新データ：`data/suken-{numbers,equations,geometry,trigonometry,powers,calculus,sequences,vectors,probability,reasoning}.json`。
- 著者用原稿：`scripts/build-suken-*.mjs`。共通形式は`scripts/suken-authoring.mjs`。
- 図解：`scripts/build-suken-figures.mjs`から`assets/images/suken/*.svg`を生成。
- `referencePages`は概念を参考にしたページ。設問の転載元や過去問識別子ではない。

リポジトリ直下で実行：

```powershell
node scripts/build-suken-content.mjs
node scripts/build-suken-pages.mjs
node scripts/test-suken-math.mjs
node scripts/test-suken-learning.mjs
```

JSONを直接直すと再生成で戻るため、内容は原稿側で変更する。
ブラウザ検証はPlaywrightとMicrosoft Edgeを使用。`PLAYWRIGHT_MODULE`環境変数でPlaywrightモジュールの場所を指定できる。

## 検証記録

- 全50項目・250問：ID、4択、正解参照、ヒント・解説、途中の一手2問と自力3問、説明の構造を検証。
- 数値回答82問：和の直接列挙、確率の全結果列挙、漸化式の反復、距離・内積・積分の計算等で照合。恒等式・解の公式の例・加法定理の例も検算。
- その他の記号・概念問題：設問・正答・誤答・理由を原稿で点検。自動検算が全問題の数学的正しさを保証するとは扱わない。
- Edge：全153説明、250回答の採点・解説、選んだだけでは採点しないこと、各分野の誤答・未選択、範囲出題、覚えた印の再読込を確認。
- 390px幅で説明・問題・結果・一覧の横はみ出しなし。スマートフォンの三角比図解とデスクトップ一覧を画像でも確認。
- 分野一覧のリンク、未知の分野・項目、データ読込失敗の案内を確認。
- 既存の√30問・展開因数分解35問を含めて回帰確認済み。
