# 社会・資料編

資料編を地理・歴史・公民の「資料問題」に振り分け、14単元261問を追加した。四択、ヒント、回答後の解説は一問一答と共通。資料を問題画面に表示し、表の比較、グラフの数値、年表の順序、制度の関係を読んで答える。

## 写真と範囲

|分野|ページ|写真末尾|単元数|問題数|
|---|---|---|---|---|
|地理|130–139|9176–9180|7|98|
|歴史|140–151|9181–9186|3|79|
|公民|152–159、憲法条文の続き（ページ番号不明）|9187–9191|4|84|

129ページは資料編の扉。9185–9189の再送は重複として扱う。各ページの主要テーマを対象とするが、全掲載語句を一語ずつ出題する構成ではない。

## 資料の扱い

写真をそのまま掲載せず、学習用の表・棒グラフ・関係図・SVGの模式図に再構成した。時差は夏時間を除外。統計には2017–2020年など原資料の年を明記し、現在の数値として問わない。気候の模式的な値は概数であることを表示する。図表には数値表や代替テキストを用意し、狭い画面では表の内部を横スクロールできる。

参議院の定数は写真の245人から248人へ更新した。[参議院の議員数](https://www.sangiin.go.jp/japanese/joho1/kousei/giin/current/giinsu.htm)、[参議院学習資料](https://www.sangiin.go.jp/japanese/taiken/bochou/pdf/student/202509-all.pdf)、[日本国憲法](https://www.shugiin.go.jp/Internet/itdb_annai.nsf/html/statics/shiryo/dl-constitution.htm)、[国土地理院の地図記号](https://www.gsi.go.jp/kohokocho/map-sign-tizukigou-2022-itiran.html)を制度・記号の確認に用いる。

## 再生成と検証

`node scripts/build-entrance-materials.mjs`で著作データからJSONを生成する。`--check`は再生成結果との一致を確認する。`scripts/test-entrance-materials.mjs`は全261問をブラウザで採点し、目次、図表の画像読み込み、ヒントのリセット、解説、画面幅320/390/1280、一問一答との分離を確認する。
