# 数検2級1次：基礎から記述問題への教材

## 学習条件と方針

- スマホを主な端末とする。理解度・学習時間は未定。
- 時間制限を設けず、説明1画面・問題1問から取り組める。
- 確認3問で前提知識の復習先を示す。自己確認であり、理解度や合格の判定には用いない。
- 各項目は「意味と解き方 → 途中の一手2問 → 選択肢なしの記述3問」。紙に途中式を書く。
- 解答・途中式・確認点を照合して自己記録する。ヒントを使った場合は復習として記録する。
- 問題はオリジナル。手元の問題集の関連ページへ進む案内を付ける。
- 元写真と確認用スクリーンショットはローカル専用。公開教材から元写真を参照しない。

## 初回実装

`pages/suken-algebra-bridge.html` に展開・因数分解の4項目を実装。

| 項目 | 主な狙い | 関連する問題集 |
| --- | --- | --- |
| 3つの項の2乗 | 9個の積から交差項をまとめる | 第1回1次 問1 p60 |
| まとまりの2乗と平方差 | 符号を含むまとまりを一つの式として見る | 第1回1次 問2 p61 |
| 平方差を繰り返す | 2乗の差を段階的に使う | 第5回1次 問1 p178 |
| 2種類の文字の因数分解 | 一つの文字について整理し、和と積を使う | 第3回1次 問1・2 p117–118 |

確認3問、説明14画面、途中の一手8問、記述12問。合計23問。
記録は端末のローカルストレージに保存し、アカウント間・端末間の同期はしない。

編集元は `scripts/suken-algebra-bridge-content.mjs`。生成コマンドは
`node scripts/build-suken-algebra-bridge.mjs`。
専用検証は `node scripts/test-suken-algebra-bridge.mjs`。
