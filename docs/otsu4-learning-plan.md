## 根拠と編集上の区別

- 試験科目：[消防試験研究センター](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/subject.html)
- 形式・合格基準：[同センター](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/way.html)
- 免状の範囲：[同センター](https://www.shoubo-shiken.or.jp/knowledge/kikenbutsu.html)
- 規制の原則：[消防法](https://laws.e-gov.go.jp/law/323AC1000000186/) 第10・11・13条、別表第一
- 指定数量と倍数：[危険物の規制に関する政令](https://laws.e-gov.go.jp/law/334CO0000000306/) 第1条の11、別表第三
- 数量の代表例・条例：[横浜市消防局](https://www.city.yokohama.lg.jp/bousai-kyukyu-bohan/shobo/kasaisonae/mijika/kyoka-todokede.html)（更新2026-08-06）
- アルコールの予防：[消防庁](https://www.fdma.go.jp/mission/prevention/alcohol/anzen.html)
- 消火原理・泡：[消防庁の教育教材](https://www.fdma.go.jp/singi_kento/kento/items/post-157/01/bessatu3.pdf)

1/5以上の少量危険物の届出は横浜市の具体例として表記し、地域の手続きを全国共通としない。
石油類の引火点区分は他の品名に一律適用しない。市販混合品・水溶液は濃度や測定値等で判定が変わるので、代表物質の例と区別する。
引火点と発火点、液体の密度と水溶性、蒸気と液体を区別する。ガソリン火災の棒状注水の問題と、適応のある冷却・噴霧等を混同しない。
理科の式は条件と単位を明記。気体の比例は一定圧力・一定物質量・理想気体、pHの基準は25℃、質量保存は閉じた系。
